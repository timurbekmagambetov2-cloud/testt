## Основные команды Git
Для эффективной работы используются следующие команды:

* `git status --short` — быстрый просмотр статуса изменений[cite: 8].
* `git log --oneline --graph --decorate --all` — визуальная история коммитов[cite: 8].
* `git checkout -b <branch_name>` — создание новой ветки и переход на нее[cite: 8].

> **Важно:** Всегда проверяйте текущую ветку перед отправкой изменений на удаленный сервер (`git push`).
